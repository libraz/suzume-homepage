# 動詞・文法表現

複合動詞、助動詞、助詞では境界の規則が異なります。一語として保持する表現と、文法上の構成要素に分ける表現を、口語・文語も含めて説明します。

比較条件と読み方は [MeCab との違い](/ja/docs/mecab-comparison#比較条件)、品詞の付け方は [POS 分類の違い](/ja/docs/pos-differences)を参照してください。

## 動詞と助動詞

### 複合動詞

連用形の動詞語幹に続く補助動詞は、複合動詞として結合されます。

<TokenDiff input="食べ続ける" mecab="食べ / 続ける" suzume="食べ続ける(VERB)" />

対応するV2要素: 込む、出す、続く、返す、合う、直す、切る、上がる、抜く、こもる、続ける、つける、替える、合わせる、上げる、下げる、掛ける、入れる 等（漢字・かな表記合わせて300以上）

「過ぎる」「かねる」のような文法化した補助要素は意図的に結合**しません** — [補助動詞の分割](#補助動詞の分割)を参照してください。

<Why>

複合動詞は日本語で単一の語彙単位として機能します。分割すると複合的な意味が失われます。

</Why>

### 希望の「たがる」

希望を外から観察して述べる助動詞「たがる」は、活用形を含めて単一の助動詞トークンとして扱います。

<TokenDiff input="食べたがる" mecab="食べ / た / がる" suzume="食べ(VERB) / たがる(AUX, lemma: たがる)" />

<Why>

「た」と「がる」はこの構文では過去＋動詞ではなく、一体で希望を表す助動詞です。

</Why>

### 補助動詞の分割

文法化した補助要素 — 過ぎる（過度）、かねる（不可能）、そびれる（機会逸失）、尽くす（完遂） — は本動詞から分割します。Suzume は拡張品詞で補助要素としての役割を示します。公開 API の品詞は `過ぎる` 系では `VERB`、下記の他の補助要素では `AUX` になります。MeCab 自身の扱いも辞書によって揺れがあり、結合される組み合わせ（飲み過ぎ）と、非自立サブカテゴリで分割される組み合わせがあります。

<TokenDiff input="飲み過ぎた" mecab="飲み(動詞) / 過ぎ(動詞・非自立) / た(助動詞)" suzume="飲み(VERB) / 過ぎ(VERB, lemma: 過ぎる) / た(AUX)" />

<TokenDiff input="わかりかねる" mecab="わかり(動詞) / かねる(動詞・非自立)" suzume="わかり(VERB, lemma: わかる) / かねる(AUX)" />

<TokenDiff input="言いそびれた" mecab="言いそびれ(動詞) / た(助動詞)" suzume="言い(VERB, lemma: 言う) / そびれ(AUX, lemma: そびれる) / た(AUX)" />

<TokenDiff input="食べ尽くす" mecab="食べ(動詞) / 尽くす(動詞・非自立)" suzume="食べ(VERB) / 尽くす(AUX)" />

<Why>

これらの補助要素は新しい語彙的動詞を作るのではなく、程度・可能性・完了といった文法的な意味を加えます。本動詞を分離しておくことで原形が検索に使え、この構文ファミリー全体に同じ規則が一貫して適用されます。

</Why>

### 卑罵の「やがる」

卑罵の補助動詞「やがる」は、動詞の連用形の後で一語として保持します。この形を IPA 辞書は「やる」と「がる」の一部に分けますが、Suzume は原形を「やがる」、拡張品詞を `AUX_卑罵` とします。

<TokenDiff input="食べやがった" mecab="食べ(動詞) / や(動詞・非自立, lemma: やる) / がっ(動詞・接尾, lemma: がる) / た(助動詞)" suzume="食べ(VERB, lemma: 食べる) / やがっ(AUX, lemma: やがる) / た(AUX)" />

### 否定の「ずに」

否定の助動詞「ず」と後続する助詞「に」は、文法上の境界を保って別々のトークンになります。

<TokenDiff input="食べずに" mecab="食べ / ず / に" suzume="食べ(VERB) / ず(AUX, lemma: ぬ) / に(PARTICLE)" />

<Why>

「ず」と「に」を分けることで、否定の助動詞と助詞の役割をそれぞれ保持します。

</Why>

### 生産的な否定の分割

閉じた語彙リストの[ナイ形容詞](/ja/docs/mecab-text#ナイ形容詞)とは異なり、生産的な「語幹＋ない」の組み合わせは分割し、語幹を検索可能に保ちます。

<TokenDiff input="揺るぎない" mecab="揺るぎない(形容詞)" suzume="揺るぎ(NOUN) / ない(ADJ)" />

<TokenDiff input="やりきれない" mecab="やりきれない(形容詞)" suzume="やりきれ(VERB, lemma: やりきれる) / ない(AUX)" />

<TokenDiff input="やむを得ない" mecab="やむを得ない(形容詞)" suzume="やむ(VERB) / を(PARTICLE) / 得(VERB, lemma: 得る) / ない(AUX)" />

### 文語・古風な語尾

文語の活用も現代語と同じ方針で文法境界を保ちます。否定、推量・当為、過去・完了、禁止、命令の各系列を扱います。例を挙げます。

- 文語否定の「ぬ」は未然形から分割: 知らぬ → 知ら＋ぬ（`AUX`）
- 文語的な「ん」も同様に分割: 乗り越えん → 乗り越え＋ん（`AUX`）
- 文語過去の「き」も独立した助動詞境界を保つ: 行かざりき → 行か＋ざり＋き

推量の「らむ」は動詞の終止形に続きます。IPA 辞書が別の名詞と動詞として解析する場合も、Suzume は動詞と助動詞の境界を保ちます。

<TokenDiff input="行くらむ" mecab="行(名詞) / くらむ(動詞)" suzume="行く(VERB) / らむ(AUX)" />

「美しかり」のような文語形容詞の連用形は活用形を一語として保持し、現代語の原形を返します。後続する過去の助動詞「けり」は分割します。

<TokenDiff input="美しかりけり" mecab="美し(形容詞, lemma: 美しい) / かり(動詞, lemma: かりる) / けり(助動詞)" suzume="美しかり(ADJ, lemma: 美しい) / けり(AUX)" />

### 口語の助動詞形

過去の推量形、母音が融合した願望形、意志形でも、助動詞の境界を保ちます。

| 入力 | Suzume |
|-------|--------|
| 食べたろう | `食べ(VERB) / たろ(AUX, lemma: た) / う(AUX)` |
| 食べてえ | `食べ(VERB) / てえ(AUX, lemma: たい)` |
| いこう | `いこ(VERB, lemma: いく) / う(AUX)` |
| ゆこう | `ゆこ(VERB, lemma: ゆく) / う(AUX)` |

## 機能語と文法上の境界

### 閉じた複合助詞 {#closed-compound-particles}

1つの助詞として機能する閉じた表現は、全体を1トークンに保ちます。

<TokenDiff input="や否や" mecab="や(助詞) / 否や(名詞)" suzume="や否や(PARTICLE)" />

採用した IPA 辞書では「と共に」や、文脈によっては「につれて」も最初から 1 トークンになるため、この比較条件では境界差として掲載しません。別の辞書では分割される場合があります。

<Why>

複合助詞は1つの文法的な語です。分割すると、意味を持たない1文字の断片が検索インデックスに散らばります。

</Why>

### 一語扱いの機能語

固定的な機能語は、辞書駆動の解析で断片化される場合でも一語として保持します。

<TokenDiff input="散歩がてら" mecab="散歩 / が / てら" suzume="散歩(NOUN) / がてら(PARTICLE)" />

<TokenDiff input="そんなら" mecab="そん / なら" suzume="そんなら(CONJ)" />

「〜のついでに」を表す「がてら」は1つの助詞、口語の「そんなら」は1つの接続詞です。

### 生産的な機能語の連鎖

生産的な構文は、綴り全体を固定した機能語とせず、内部の動詞・助詞境界を保ちます。

<TokenDiff input="とすれば" mecab="とすれば(接続詞)" suzume="と(PARTICLE) / すれ(VERB, lemma: する) / ば(PARTICLE)" />

「をもって」も同じ規則で「を / もっ / て」になります。生産的な動詞境界を含まない閉じた表現は、上の[「や否や」](#closed-compound-particles)のように全体を保ちます。

節末の助詞に続く引用の「って」も、独立した助詞として保ちます。`行くかって` は `行く(VERB) / か(PARTICLE) / って(PARTICLE)` になります。

### 副詞的名詞＋助詞

比較辞書が1つの機能語として語彙化する一部の並びを、名詞＋助詞のまま保持します。

<TokenDiff input="次に" mecab="次に(接続詞)" suzume="次(NOUN) / に(PARTICLE)" />

<TokenDiff input="後で行く" mecab="後で(副詞) / 行く" suzume="後(NOUN) / で(PARTICLE) / 行く(VERB)" />

<Why>

名詞を分離しておくことで検索語として使え、その副詞が辞書に載っているかどうかに関係なく同じ境界が適用されます。

</Why>

### 先頭の固定単位

連体詞「わが」は後続の名詞から分割します。

<TokenDiff input="わが国" mecab="わが国(名詞)" suzume="わが(DET) / 国(NOUN)" />

### お・ご接頭辞

Suzume はお/ごの敬語接頭辞を名詞から分割しますが、不可分な語彙の場合は結合を維持します。

<TokenDiff input="お茶" mecab="お茶(名詞)" suzume="お(PREFIX) / 茶(NOUN)" note="split — separable prefix" noteJa="分割 — 分離可能な接頭辞" />

Suzume が一語に保つ例外には、お金、お前、おかず、おでん、おもちゃ、おすすめ、おいら、おっさん、お疲れ様、おいで、および家族語（お母さん、お父さん、お兄ちゃん、お姉さん、おじさん、おばさん、おじいさん、おばあさん等）があります。比較対象の MeCab も多くを一語に保ちますが、「お兄ちゃん」「お姉さん」は「お」の後で分割します。

<Why>

多くの文脈では、お/ごは分離すべき文法的接頭辞です。しかし一部の語は接頭辞と語彙化しており、分割すると不正確になります。

</Why>

### タリ活用副詞

タリ活用の副詞語幹に「と」が続く場合、単一の副詞に結合されます。

<TokenDiff input="堂々と" mecab="堂々 / と" suzume="堂々と(ADV)" />

対象語幹: 泰然、堂々、悠々、淡々、粛々、颯爽、毅然、漫然、茫然、呆然、唖然、愕然、断然、歴然、整然、雑然、騒然、憮然、黙然、昂然、厳然

<Why>

これらの語幹＋と の組み合わせは慣用的に副詞として使われ、単一トークンの方が有用です。

</Why>

### 漢語＋「として」

「依然として」のような固定したタリ副詞構文は、MeCab では1つの副詞です。Suzume は副詞形と「する」の活用を分割します。「名詞として」のような生産的な表現は、どちらの解析器でも文法境界を持ちます。

<TokenDiff input="依然として" mecab="依然として(副詞)" suzume="依然と(ADV) / し(VERB) / て(PARTICLE)" />

<Why>

これらはタル形容詞の副詞形（漢語＋と）に続くする活用です。分割することでより正確な文法構造を提供します。

</Why>

## 述語と代名詞

### コピュラ否定

名詞述語の後では、「じゃ」をコピュラ、「ない」を形容詞として扱います。コピュラの文脈を明示するため、比較には名詞側も含めます。

<TokenDiff input="本じゃない" mecab="本(名詞) / じゃ(助詞) / ない(助動詞)" suzume="本(NOUN) / じゃ(AUX, lemma: だ) / ない(ADJ)" />

<Why>

名詞の文脈からコピュラの用法を判定し、否定との境界を保ちます。

</Why>

### 使役受身

MeCab は五段動詞の未然形＋使役「さ」を1トークンに結合する場合があります。Suzume はこの不整合を正規化します。

<TokenDiff input="飲まされた" mecab="飲まさ(動詞) / れ(動詞・接尾) / た(助動詞)" suzume="飲ま(VERB, lemma: 飲む) / さ(AUX, lemma: す) / れ(AUX) / た(AUX)" />

<Why>

比較に使う IPADIC の解析は、一部の使役受身形を分割し（読ま + さ + れた）、他を結合します（飲まさ + れた）。Suzume はこれらの構文に同じ分割規則を適用します。

</Why>

### 形式名詞「ふう」

指示連体詞に続く「ふうに」は、連体詞・形式名詞・助詞という文法単位に分割します。

<TokenDiff input="そんなふうに" mecab="そんなふうに(副詞)" suzume="そんな(DET) / ふう(NOUN) / に(PARTICLE)" />

### 不定の「か」

疑問代名詞に付く不定の「か」は代名詞から分割し、その後の存在動詞「いる」は本動詞として扱います。

<TokenDiff input="なにかいる" mecab="なにか / いる" suzume="なに(PRON) / か(PARTICLE) / いる(VERB)" />

<Why>

「か」は代名詞の一部ではなく不定を作る助詞であり、「いる」はこの文脈では進行の補助動詞ではありません。

</Why>
